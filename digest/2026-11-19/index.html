① 今日 Top 热点

  1. Nginx 曝出两个 HTTP/2 免登录远程代码执行漏洞，影响可追溯到 2015 年

    Wiz 与 Rapid7 等多家团队独立发现 CVE-2026-123633 和 CVE-2026-123007，CVSS 4.0 均为 9.2，前提是开启了 HTTP/2；其中 123007 影响 1.9.5 起的版本（Wiz 表格列到 1.31.8）。F5 于 11 月 18 日发布安全更新，Wiz 同时列出 HTTP/3、DNS 解析、邮件代理等多个相关漏洞。建议尽快升级；暂时不能升级可先关闭 HTTP/2（http2 off; 并去掉 listen 上的 http2 参数）。HN 约 1,070 分。

    wiz.io news.ycombinator.com
  2. 谷歌 AI 摘要让外部网站点击少约 40%，柏林生活指南站流量掉了 75%

    RevScope 汇总的随机实验显示，出现 AI Overview 时点向外部网站的点击约减少 40%；DataForSEO 跟踪的关键词里出现 AI 摘要的比例从 2024 年 9 月的 5.93% 升到 2026 年 8 月的 61.43%，而 AI 助手 3 月只给网站带来 0.3% 的流量。同日，独立站 All About Berlin 站长写道，运营 8 年后流量被 AI 摘要拿走约 75%。两帖在 HN 分别约 690 和 750 分。

    revscope.co nicolasbouliane.com news.ycombinator.com news.ycombinator.com

    blog.google github.blog news.ycombinator.com

    microsoft.ai news.ycombinator.com

    europeanbusinessmagazine.com news.ycombinator.com

② 这周容易火 / 可执行方向

  • Nginx 暴露面自查 — 一个 CLI / GitHub Action：扫描配置和镜像里的 Nginx 版本、是否开 HTTP/2 和 HTTP/3、是否用了 resolver 或 mail 代理，对照 Wiz 披露的受影响范围输出升级清单和临时关 HTTP/2 的改法。免费引流，托管巡检收费。
  • 多模型成本路由器 — Gemini 4 Neon、GPT-6.2、MAI 系列一周内接连降价：做一个按任务类型自动选最便宜且合格模型的网关，用你自己的样例做小规模回归，月底出账单对比。开源核心 + 托管版按调用量收费。
  • 关键依赖「消失险」 — ONNX Runtime 仓库无预告 404、Codeberg 一度不可达：一个 GitHub App 自动给项目依赖的上游仓库和发布包做镜像，上游删除、改名或转私有时告警并自动切到镜像。按仓库收费。
  • AI 摘要引用追踪 — AI 摘要让点击少约 40%：做一个工具，定期在主流 AI 搜索里问你行业的问题，记录谁被引用、你的页面有没有被提到，并给出「更易被引用」的页面改写建议。按站点订阅。
  • Agent 技能质检 — NVIDIA SkillEvaluator、last30days-skill 等技能类仓库同时上榜，GitHub 又给 Copilot 加了 8 个连接器：做一个技能上架前的评测服务，测触发准确率、和现有技能的重叠以及对 Agent 行为的影响，出可分享的报告徽章。

② 补充：受众更广的方向

  • 上一节更偏开发者。下面 6 条面向普通人或大量中小商家：能用现成 AI 在一周内做出可用的 MVP，并有可查证的需求信号。数字都来自公开出处，查不到的规模就不写。
  • 小商家「AI 搜索曝光」体检 — 店主输入店名和所在城市，工具模拟顾客在谷歌 AI 摘要、ChatGPT、Gemini 里常问的问题（附近哪家好、营业时间、价格），看自己有没有被提到、信息对不对，并给出改进清单。
    面向谁、为何广：RevScope 数据：AI 摘要已出现在约 61% 的被跟踪关键词上，出现时外部网站点击少约 40%；连做了 8 年的柏林指南站也丢了约 75% 流量。餐馆、诊所、维修、民宿等本地商家都靠搜索被找到。 RevScope 数据 All About Berlin 自述
    怎么做（一周 MVP）：一周用各家 API 跑固定问题集，AI 汇总「被提到 / 没提到 / 说错了」，自动生成要补的商家资料、常见问答和点评回复模板。
    怎么赚钱：免费体检一次；每月复查和改进建议按店收月费；代运营公司批量授权。
    风险：AI 回答每次不同，要多次采样并说明不确定性；不能承诺「上 AI 推荐」；遵守各平台 API 条款。
  • 自媒体与小网站的「流量转型」助手 — 把博客或指南站的内容一键改编成邮件订阅、短视频脚本、可下载清单和付费小册，减少对搜索流量的依赖，并追踪每个新渠道的效果。
    面向谁、为何广：All About Berlin 站长说许多站长私下反映同样遭遇，有人加了付费墙、有人停更；AI 摘要覆盖率两年内从约 6% 升到约 61%。大量旅游、生活、教程类博主都受影响。 站长原文 HN 讨论
    怎么做（一周 MVP）：一周做导入站点地图 → AI 按主题拆成邮件序列、短视频脚本和清单 → 接现成邮件服务与支付链接，附渠道看板。
    怎么赚钱：按站点月费；代做付费小册抽成；与邮件服务商做推荐分成。
    风险：改编要尊重原作者版权，只处理用户自己的内容；新渠道需要时间起量，不能承诺收入。
  • 「条款大白话」：注册前看清你同意了什么 — 用户粘贴或在浏览器里打开任何服务条款，AI 标出仲裁条款、数据出售/营销用途、自动续费和退出期限，并提醒在期限内完成退出（例如 30 天内拒绝仲裁）。
    面向谁、为何广：Consumer Rights Wiki 整理：在美国用 ID.me 登录 IRS 需接受其条款，争议默认走仲裁、30 天内可退出；该帖 HN 约 490 分。几乎每个人每周都在点「同意」，却很少读。 Consumer Rights Wiki HN 讨论
    怎么做（一周 MVP）：一周做浏览器插件 + 网页版：抓取条款文本，AI 按固定清单提取要点并给出原文出处，加日历提醒。
    怎么赚钱：免费基础版；家庭版按年订阅（多成员、提醒、条款变化追踪）；消费者组织或律所合作推荐。
    风险：不能当作法律意见，要显示原文并提示咨询专业人士；AI 漏标或误读要有免责声明和反馈入口。
  • 小微企业「报税前自查」助手 — 店主上传银行流水、发票和记账表，AI 像审计师一样提问：哪些收支对不上、哪些发票缺失、哪些大额支出要补说明，生成给会计的整理包。
    面向谁、为何广：KPMG 试验中 AI Agent 有时比审计团队问得更深；谷歌称 Gemini 4 Neon 在 Tax Agent Bench 与表格建模类评测上排第一（厂商口径）。小商家和个体户每年都要报税，多数请不起完整审计。 KPMG 试验报道 Gemini 4 Neon 发布
    怎么做（一周 MVP）：一周做上传与对账页：表格自动匹配流水和发票，AI 生成问题清单和补件提醒，导出 PDF / Excel。
    怎么赚钱：按报税季单次收费；记账代理批量版按客户数收费；推荐合作会计抽成。
    风险：财务数据极敏感，需加密和明确删除策略；不能代替持证会计签字；各地税法不同要写清适用范围。
  • 小团队的「云工具搬家与备份」 — 一键把 Slack、Notion、Google Drive、M365 里的数据定期备份成可读格式，并在需要时迁移到更便宜或开源的替代品，附迁移清单。
    面向谁、为何广：Show HN 的 ExitPath（离开 Slack、Notion、M365 的开源路径）约 140 分；同一天 ONNX Runtime 仓库无预告消失、Codeberg 一度不可达，提醒依赖单一平台的风险。大量小团队把全部资料放在几个 SaaS 里。 ExitPath ONNX Runtime 讨论
    怎么做（一周 MVP）：一周用官方导出 API 做定时备份到用户自己的网盘，AI 把导出结果整理成可搜索的归档，并生成迁移步骤。
    怎么赚钱：按团队人数月费；一次性迁移服务收项目费；与替代产品做推荐分成。
    风险：需要高权限授权，安全和隐私要过关；各平台导出接口有限制和变更风险；不能绕过平台条款抓取数据。
  • 小网站的「补丁翻译官」 — 站主验证域名所有权后，工具检查自己网站公开可见的服务器信息（如是否开 HTTP/2），对照最新安全公告，用大白话说明要不要处理，并生成可直接发给建站外包的操作说明。
    面向谁、为何广：Wiz 称 Nginx 是使用最广的开源 Web 服务器、支撑超过 2.25 亿个网站，这次漏洞影响到 2015 年的版本。大量小商家网站由外包搭建，店主看不懂公告也不知道该问什么。 Wiz 披露 HN 讨论
    怎么做（一周 MVP）：一周做域名验证（DNS TXT）+ 公开信息检查 + 安全公告订阅，AI 生成大白话说明和给外包的工单模板。
    怎么赚钱：免费检查一次；按站点月费获得持续提醒；建站公司批量版。
    风险：只能检查已验证的自有网站，不能扫描他人；公开信息看不出全部风险，要写明以服务商确认为准。

    怎麼做（一週 MVP）：一週用各家 API 跑固定問題集，AI 彙總「被提到 / 沒提到 / 說錯了」，自動生成要補的商家資料、常見問答和點評回覆模板。
    怎麼賺錢：免費體檢一次；每月複查和改進建議按店收月費；代運營公司批次授權。
    風險：AI 回答每次不同，要多次取樣並說明不確定性；不能承諾「上 AI 推薦」；遵守各平臺 API 條款。
  • 自媒體與小網站的「流量轉型」助手 — 把部落格或指南站的內容一鍵改編成郵件訂閱、短影片指令碼、可下載清單和付費小冊，減少對搜尋流量的依賴，並追蹤每個新渠道的效果。

    怎麼做（一週 MVP）：一週做匯入站點地圖 → AI 按主題拆成郵件序列、短影片指令碼和清單 → 接現成郵件服務與支付連結，附渠道看板。
    怎麼賺錢：按站點月費；代做付費小冊抽成；與郵件服務商做推薦分成。
    風險：改編要尊重原作者版權，只處理使用者自己的內容；新渠道需要時間起量，不能承諾收入。
  • 「條款大白話」：註冊前看清你同意了什麼 — 使用者貼上或在瀏覽器裡開啟任何服務條款，AI 標出仲裁條款、資料出售/營銷用途、自動續費和退出期限，並提醒在期限內完成退出（例如 30 天內拒絕仲裁）。

    怎麼賺錢：免費基礎版；家庭版按年訂閱（多成員、提醒、條款變化追蹤）；消費者組織或律所合作推薦。
    風險：不能當作法律意見，要顯示原文並提示諮詢專業人士；AI 漏標或誤讀要有免責宣告和反饋入口。
  • 小微企業「報稅前自查」助手 — 店主上傳銀行流水、發票和記賬表，AI 像審計師一樣提問：哪些收支對不上、哪些發票缺失、哪些大額支出要補說明，生成給會計的整理包。

    怎麼做（一週 MVP）：一週做上傳與對賬頁：表格自動匹配流水和發票，AI 生成問題清單和補件提醒，匯出 PDF / Excel。
    怎麼賺錢：按報稅季單次收費；記賬代理批次版按客戶數收費；推薦合作會計抽成。
    風險：財務資料極敏感，需加密和明確刪除策略；不能代替持證會計簽字；各地稅法不同要寫清適用範圍。
  • 小團隊的「雲工具搬家與備份」 — 一鍵把 Slack、Notion、Google Drive、M365 裡的資料定期備份成可讀格式，並在需要時遷移到更便宜或開源的替代品，附遷移清單。
    面向誰、為何廣：Show HN 的 ExitPath（離開 Slack、Notion、M365 的開源路徑）約 140 分；同一天 ONNX Runtime 倉庫無預告消失、Codeberg 一度不可達，提醒依賴單一平臺的風險。大量小團隊把全部資料放在幾個 SaaS 裡。 ExitPath ONNX Runtime 討論
    怎麼做（一週 MVP）：一週用官方匯出 API 做定時備份到使用者自己的網盤，AI 把匯出結果整理成可搜尋的歸檔，並生成遷移步驟。
    怎麼賺錢：按團隊人數月費；一次性遷移服務收專案費；與替代產品做推薦分成。
    風險：需要高許可權授權，安全和隱私要過關；各平臺匯出介面有限制和變更風險；不能繞過平臺條款抓取資料。
  • 小網站的「補丁翻譯官」 — 站主驗證域名所有權後，工具檢查自己網站公開可見的伺服器資訊（如是否開 HTTP/2），對照最新安全公告，用大白話說明要不要處理，並生成可直接發給建站外包的操作說明。
    面向誰、為何廣：Wiz 稱 Nginx 是使用最廣的開源 Web 伺服器、支撐超過 2.25 億個網站，這次漏洞影響到 2015 年的版本。大量小商家網站由外包搭建，店主看不懂公告也不知道該問什麼。 Wiz 披露 HN 討論
    怎麼做（一週 MVP）：一週做域名驗證（DNS TXT）+ 公開資訊檢查 + 安全公告訂閱，AI 生成大白話說明和給外包的工單模板。
    怎麼賺錢：免費檢查一次；按站點月費獲得持續提醒；建站公司批次版。
    風險：只能檢查已驗證的自有網站，不能掃描他人；公開資訊看不出全部風險，要寫明以服務商確認為準。
