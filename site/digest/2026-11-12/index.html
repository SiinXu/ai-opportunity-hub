早间技术热点 · 2026-11-12

上海时间早间例行简报：AI、开源、安全与一人公司可执行信号。

① 今日 Top 热点

  1. AWS 发布 AWS Emulator：给编码 agent 用的本地 AWS 模拟器

    开源的本地 AWS API 模拟器，不需要 AWS 账号、不额外收费，可在本机、开发服务器或 CI 里测试代码；支持服务器模式（AWS CLI 和任意 SDK）和 Rust 测试的嵌入模式，每个版本公布各服务与真实 AWS 的吻合度分数。Werner Vogels 博客上 Swami 的文章说，它的全部代码由 agent 编写和测试，基于 400 多个 API 模型、覆盖 200 多个 AWS 服务。HN 约 605 分、205 条评论。

    github.com allthingsdistributed.com news.ycombinator.com
  2. 用 AI agent 分析 NASA 激光雷达数据，72 小时「找到」一处玛雅遗址

    作者把约 1,200 平方公里丛林的 lidar 数据转成图像，让 48 个 agent 按指南逐张找金字塔、平台和广场，排除自然山丘和天坑；其中一处悬崖边的山顶遗址不在墨西哥 INAH 登记册中，作者 72 小时内拿到官方回复。更新：该遗址已在 2025 年的论文里被测绘过，所以是「重新发现」。HN 今日最高分，约 912 分、335 条评论。

    pietromiotti.com news.ycombinator.com
  3. Python 核心开发者、《Python 之禅》作者 Tim Peters 去世

    Guido van Rossum 在 Python 官方论坛宣布，Tim Peters 已于今年 7 月 15 日去世。他写下了 PEP 20《Python 之禅》，2002 年设计的 Timsort 排序算法后来被 Java 和 Android 采用，也因在邮件列表上耐心细致的解答被称为「Timbot」。HN 约 800 分。

    discuss.python.org news.ycombinator.com

    wsj.com nytimes.com news.ycombinator.com
  5. 美联航禁止个人 AI agent 代订机票

    美联航称把账户凭证交给第三方 AI 助手有安全风险，可能导致意外购票、账户变更或里程被用，用 agent 值机还可能违反联邦规定，因此会在自家平台和旅行社、聚合平台上限制未授权的个人 AI agent；分析师认为它不想再多一个中间商。西南航空则相反，把航班库存开放给 ChatGPT 用户。HN 约 286 分、268 条评论。

    cbsnews.com news.ycombinator.com
  6. Google 推出 Gemini Decisions API：一次前向计算给出带置信度的判断

    新端点由 Gemini Decision 1 模型驱动，专做是非、多选和评分量表这类封闭式判断：一份多模态输入（文本、图像、音频、视频、PDF，最长 256K tokens）可同时问最多 1,000 个问题，不逐 token 生成，直接返回概率和置信度，端到端 150–250 毫秒，每百万输入 token 0.10 美元、输出不计费，适合路由、内容评分和策略检查。HN 约 224 分。

    blog.google news.ycombinator.com
  7. 一次假火警差点淹掉 Jane Street 唯一的纽约机房

    前系统团队成员回忆：施工粉尘触发烟感，烟感自动关掉机房空调，同时让喷淋管道充水，而喷头靠温度触发；他冲回大楼，在室温升到约 143°F 时把每台设备的电源线拔掉才保住机房。事后他用 OCaml 写了一个监控：每分钟取所有服务器温度的平均值，略高就报警。HN 约 389 分、190 条评论。

Morning tech digest · 2026-11-12

Morning brief (Asia/Shanghai): AI, open source, security, and actionable signals for one-person companies.

① Top stories

  1. AWS releases AWS Emulator, a local copy of the AWS APIs for coding agents to test against

    An open-source local emulator of the AWS APIs: no AWS account and no extra fee, for testing on your machine, a dev server, or CI; it offers a server mode for the AWS CLI and any SDK plus an embedded mode for Rust tests, and publishes per-service fidelity scores with each release. In a guest post on Werner Vogels’ blog, Swami says all of its code was written and tested by agents, built from more than 400 API models covering over 200 AWS services. ~605 points and 205 comments on HN.

    github.com allthingsdistributed.com news.ycombinator.com
  2. AI agents scanned NASA lidar data and (re)discovered a Maya site in 72 hours

    The author turned lidar strips covering about 1,200 km² of jungle into images and had 48 agents go through them following a guide, looking for pyramids, platforms and plazas while filtering out natural hills and sinkholes; one cliff-edge hilltop site was missing from Mexico’s INAH register, and an official reply came within 72 hours. Update: archaeologists had already mapped it in a 2025 paper, so it was a rediscovery. Top HN post of the day, ~912 points and 335 comments.

    pietromiotti.com news.ycombinator.com
  3. Tim Peters, author of the Zen of Python and Timsort, has died

    Guido van Rossum announced on the Python forum that Tim Peters died on July 15 this year. He wrote PEP 20, the Zen of Python, designed Timsort in 2002 (later adopted by Java and Android), and was nicknamed “Timbot” for his patient, careful answers on the mailing lists. ~800 points on HN.

    discuss.python.org news.ycombinator.com
  4. WSJ: Nvidia’s board is preparing to oust CEO Jensen Huang

    Citing people familiar with the matter, the Wall Street Journal reports the board is preparing to remove him after an investigation into two extramarital affairs, one with a woman alleged to be a spy and one with an employee, and could meet as soon as Wednesday; the New York Times also reported a relationship with an executive who reports to him. The news spread quickly on X; these are press reports with no official company decision yet. ~320 points and 301 comments on HN.

    wsj.com nytimes.com news.ycombinator.com
  5. United Airlines bans personal AI agents from booking flights for travelers

    United says sharing account credentials with third-party AI assistants risks unintended purchases, account changes or use of MileagePlus miles, and that agent check-in could breach federal rules, so it will restrict unauthorized personal AI agents on its own platforms and via travel agencies and aggregators; an analyst says it does not want another intermediary. Southwest, by contrast, opened its inventory to ChatGPT users. ~286 points and 268 comments on HN.

    cbsnews.com news.ycombinator.com
  6. Google launches the Gemini Decisions API for fast, calibrated multimodal decisions

    A new endpoint powered by the Gemini Decision 1 model for closed-set decisions (yes/no, multiple choice, rubric scores): one multimodal input (text, images, audio, video, PDFs, up to 256K tokens) can carry up to 1,000 questions, scored in a single forward pass with probabilities and confidence scores in 150–250 ms end to end, at $0.10 per 1M input tokens with no output tokens billed; aimed at routing, grading and policy checks. ~224 points on HN.

    blog.google news.ycombinator.com
  7. How a false smoke alarm almost drowned Jane Street’s only NYC datacenter

    A former systems-team member recalls contractor dust tripping the smoke alarm, which shut down the room’s cooling and pressurized the sprinkler pipes, whose heads open on heat; he ran back and pulled every power cord as the room hit about 143°F. Afterwards he wrote an OCaml monitor that averages every server’s temperature each minute and alerts if it rises even slightly. ~389 points and 190 comments on HN.

    michael.bacarella.com news.ycombinator.com
  8. Atuin Threads: one searchable, synced history for every agent session on every machine

    New in Atuin 18.24: agent sessions scattered across tools and machines go into Atuin’s encrypted sync, so you can search them, resume them anywhere with atuin resume, or fork a session into another agent harness, for example starting in Claude Code on a dev server and finishing in Codex on a laptop. ~185 points on HN.

    blog.atuin.sh news.ycombinator.com
