# OPC Radar — 一人公司商机雷达
Static site in `site/` (GitHub Pages). Data: `site/data/items.json`.
Refresh (on demand): `pip install argostranslate opencc-python-reimplemented && python3 scripts/refresh.py` — pulls GitHub search (10 topics + new this week), HN (AI/LLM/agent, Show HN, Launch HN, front page), Hugging Face trending, Lobsters, DEV; merges `scripts/curated.json` (deals/ideas); translates titles+summaries into 10 locales offline (cache `scripts/i18n_cache.json`). `--no-translate` to skip. Optional `GITHUB_TOKEN` for rate limits. To automate: move `ops/workflows/*.yml` into `.github/workflows/` (needs a token with workflow scope). Until then publish with `git subtree push --prefix site origin gh-pages`.
