# OPC Radar v2 — "Violet Aurora + Lime Signal"
Studied previews in ui-hub/previews: React Bits, Aceternity UI, Magic UI, Cult UI, Hover.dev, Tremor.
Borrowings:
1. React Bits — deep violet (#120a2e→#2a1260) silk/aurora backdrop with grain noise; dark is the hero theme.
2. React Bits / Cult UI — pixel/mono display face (Silkscreen + JetBrains Mono) for labels, counters, kickers; body stays sans.
3. Aceternity UI — cursor spotlight on cards (radial-gradient following --mx/--my) + 1px gradient "beam" border on hover.
4. Aceternity UI — glass panels floating over the dark backdrop, stacked/tilted hero "window".
5. Magic UI — bento grid for Picks (one 2×2 feature tile, mixed spans), shimmer on primary button, animated gradient border pill.
6. Magic UI — big, tight display headline (-0.04em) with gradient text in the accent line.
7. Hover.dev — chunky electric accent CTA (lime #c6ff3d on violet) with hard offset shadow; tags as solid-filled chips.
8. Tremor — KPI stat strip: large tabular numbers + tiny uppercase labels + mini bar per channel.
9. Cult UI — terminal footer line (`npx`-style mono strip) under hero.
10. Light theme = lavender mist (#f5f3ff) with violet ink, lime becomes deep olive-lime for contrast — not paper/zinc.
Explicitly avoided: Linear thin rails grid, zinc+gold, B&W editorial, UI Hub cyan-pink.
