  3. 微软：中朝黑客在用开源 AI 渗透框架 ARTEX，有的入侵在三小时内拿到高权限

  4. Anthropic：让 Claude 把 Messages API 从 Python 改写成 Rust，难点是验证

    Anthropic 发文说，Messages API 是客户和 Claude Code 等自家应用访问 Claude 的主要入口，2024 年初到 2026 年秋流量涨到约 1,800 倍；Claude 约一周写出核心请求路径的第一版，真正难的是证明新旧一致：Python 版一直在变，模型输出本身不确定，而且他们看不了客户请求。做法是把生产中的 Messages API 变成验证器：让新旧两版在生产流量上并行比对，再自动派 Claude 智能体去修复差异。结果是每个请求约少用 70% CPU、首 token 中位时间约快 20%，期间没停机；其中 CPU 数字来自一个地区，首 token 数字来自 Claude Code 请求且时间较短，都是 Anthropic 自述，未经独立测量。文中还说他们审查移植的测试时发现了 100 多处被放宽的断言，以及测试通过率约 98% 时生产输入只有约四分之一一致。X 话题摘要（由 X 自动生成，未经独立核实）也在转这篇。

② 这周容易火 / 可执行方向

  • 生产流量“新旧对比”验证器 — Anthropic 说改写 API 最难的是验证，测试通过率约 98% 时生产输入只有约四分之一一致：一周做一个开源工具，把线上请求记录下来同时发给旧服务和新服务，按差异类型聚类，并生成可复现的最小用例交给 AI 修。先服务要做重写或升级框架的小团队，按托管和报告收费；注意脱敏，不碰客户明文请求。
  • Agent 技能 / 插件“偷偷联网”审计器 — Convex 的技能被指把用户想法发往远程主机、还教代理拆分命令：一周做一个命令行加 GitHub Action，扫描 SKILL.md 和插件目录里的 curl 管道 bash、向外 POST 的请求、“绕过分类器”之类的话术，输出风险报告和人话说明。卖给团队内部的插件市场和公司里统一管理代理的人；只报告发现的事实，不下“恶意”结论。
  • GitHub 令牌“体检和自动过期” — 1Password 说攻击者从一名员工的 GitHub 账号入手，SAP 被报道员工令牌被盗：一周做一个 GitHub App，列出组织里所有个人令牌、OAuth 应用和部署密钥的权限、最后使用时间，标出过宽和很久没用的，一键发提醒或到期。卖给没有专职安全人员的几十人团队，按成员数订阅；只读权限起步，先不做自动吊销。
  • 针对 AI 攻击框架的日志检测规则包 — ARTEX 的特点是快而且“吵”（英国 NCSC 的说法）：一周把公开报道里的行为特征（短时间大量侦察、凭证尝试、扫描公开仓库里的密钥）写成 Sigma 规则和云日志查询，附中英文处置清单。卖给小型 IT 外包和托管服务商，按月更新订阅；只用公开资料，不发布攻击代码。
  • “生成者—评估者”多代理脚手架 — X 话题摘要（由 X 自动生成，未经独立核实）说，开发者正从调提示词转向做“外壳”：规划、生成、评估三个代理加测试和规则，让单个代理做不成的项目做成：一周做一个可直接套用的模板，带评估代理的验收清单、成本上限和失败回退，覆盖网页和脚本两类任务。靠模板包和咨询变现；先拿自己真实项目做对比，成本和成功率只报告实测。

② 补充：受众更广的方向

    面向谁、为何广：Infohawk 报告 5 家网店在黑五前一周被植入走 WebRTC 的盗刷脚本，脚本只在手机结账页启用，桌面检查和首页扫描可能看不到；它们是通过营销像素、同意横幅设置、CDN 文件等不同方式进来的。任何接受在线付款的小店都用第三方脚本，却很少有人逐个看过。 Infohawk 报告 HN 讨论
    怎么做（一周 MVP）：一周做：先用无头浏览器模拟手机结账流程（到支付前一步为止，不输入真实卡号）→ 收集脚本和网络请求 → 与一份公开的已知域名和特征清单比对，AI 把结果写成人话 → 每周自动复查并发邮件。
    怎么赚钱：免费体检一次，月费做定期复查和变更提醒；卖给建站服务商和代运营公司做批量版。
    风险：只能发现已知特征，不能保证没事；要避免触发店铺的反爬或下单；不能在没授权时扫别人的网站。
  • 小公司“我用的软件出事了吗”提醒 — 用户勾选自己公司用的 10 到 30 个软件（密码管理器、ERP、代码托管等），工具盯着这些厂商的安全公告和主流媒体报道，出事时发一封人话邮件：发生了什么、和你有没有关系、你现在该做什么。

    怎么做（一周 MVP）：一周做：整理 50 个常见软件的公告页和 RSS → 定时抓取并让 AI 判断“是否真的有客户影响”及建议动作 → 用户按软件订阅 → 邮件和聊天机器人推送，并保留原文链接。

  • 小应用和社群的“未成年人年龄限制新规”清单 — 小应用开发者或社群管理员回答几个问题（面向哪些地区、有没有推荐流、有没有夜间通知、用户是否可能未满 18 岁），工具列出可能适用的新规、生效日期和需要准备的事项。

  1. A card skimmer that moves data over WebRTC hit five online stores the week before Black Friday

    Security firm Infohawk says the stores of Lascana, Samsonite, American Tourister, Revolve and FWRD were infected in the week before Black Friday, and that the script was removed on 24 or 25 November after its reports; it saw test card details leave in action on only one of them, Lascana. The script ran only on small or touch screens at checkout and sent the card number, expiry, security code and the shopper’s name, address, phone and email before the store checked the payment, so a card could be taken even if the order was declined. It opens the WebRTC connection with ordinary web requests, then both the malicious code and the stolen data travel over the WebRTC data channel, which rules that only watch ordinary requests do not see. Infohawk advises every payment page to set a connect-src rule listing only the hosts it uses, which blocks the first two requests; shoppers should check statements, especially debit cards, and call their bank at once. How many shoppers were affected is unknown. About 401 points and 203 comments on HN.

  2. SAP confirms a security incident; reports say employee GitHub tokens were stolen and source code may have been copied and changed

    German software company SAP told several outlets it found “suspicious activity” and took steps to protect customers, and says it has found no evidence of unauthorized access to customer business data. Der Spiegel reported first that attackers obtained employee authentication tokens and used them to copy and even modify source code on GitHub; Handelsblatt says the internal operation is code-named “Project Granite” and that SAP restricted GitHub access, halted automated development processes and replaced signing keys. heise notes that insiders say the attackers may have used agentic AI, which SAP has not confirmed, and SAP has not said how the attackers got in, which repositories were affected, or whether any altered code reached software delivered to customers.   3. Microsoft: Chinese and North Korean crews use the open-source AI pentest framework ARTEX, some reaching privileged access in under three hours

    The Register reports that Microsoft says Chinese and North Korean state-backed groups use ARTEX, an open-source, AI-powered penetration-testing framework that attackers have used to automate reconnaissance, credential attacks and exploitation since its public release in July. Campaigns linked to it have targeted cloud environments, IT software such as ConnectWise and financial institutions, sometimes reaching privileged access in under three hours; Microsoft says it can go from reconnaissance to persistent privileged access within minutes, depending on configuration and the target’s defenses. ARTEX adds no new attack techniques; its value is chaining known ones at machine speed, and The Register, citing Infrawatch, says more than 130 variants are in circulation. The UK NCSC’s warning this week notes that these tools are noisy and easier to spot in logs.

    theregister.com
  4. Anthropic: Claude rewrote the Messages API from Python to Rust, and verification was the hard part

    Anthropic writes that the Messages API is the main way customers and its own apps such as Claude Code reach Claude, with traffic growing about 1,800 times from early 2024 to fall 2026. Claude wrote a first version of the core request path in about a week; the hard part was proving parity, because the Python API kept changing, model output is nondeterministic, and the team cannot read customer requests. Their answer was to turn the production Messages API into a verifier: run old and new on production traffic in parallel and automatically dispatch Claude agents to fix the differences. The result is about 70% less CPU per request and about 20% lower median time to first token, with no downtime; the CPU figure comes from one region and the latency figure from Claude Code requests over a shorter period, and both are Anthropic’s own, not independently measured. The post also says an audit of ported tests found more than 100 weakened assertions, and that at about 98% of tests passing only about a quarter of production inputs matched. An X topic summary (auto-generated by X, not independently verified) also circulates the post.

    La société de sécurité Infohawk dit que les magasins de Lascana, Samsonite, American Tourister, Revolve et FWRD ont été infectés dans la semaine précédant le vendredi noir, et que le script a été retiré le 24 ou 25 novembre après ses rapports; il a vu les détails de la carte de test laisser en action sur un seul d'entre eux, Lascana.
