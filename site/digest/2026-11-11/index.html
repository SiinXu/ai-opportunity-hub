早间技术热点 · 2026-11-11

上海时间早间例行简报：AI、开源、安全与一人公司可执行信号。

① 今日 Top 热点

  1. DeepMind 发布 AlphaProof Code：AI agent 形式化验证了 Signal 协议的真实代码

    DeepMind 称这是多模型 agent 框架：人类专家和 AI 一起把 Signal 的安全目标写成形式化规格，再由 Gemini Carbon 驱动的 agent 生成 600 多万行 Lean 证明，只有约 1% 需要人工复核，全程约四周；把两个已修复的真实漏洞放回隔离版本后，系统都证明了有漏洞的版本不安全。HN 约 560 分、174 条评论。

    deepmind.google news.ycombinator.com
  2. Anthropic 推出 Claude Whiteboards、Claude Sheets，Dashboards 正式更名 Claude Data

    Whiteboards（团队和 Claude 一起头脑风暴的共享白板）和 Sheets（Claude 生成并编辑带公式、下拉框的表格）进入测试，Claude Dashboards 正式可用并改名 Claude Data，新增认证查询和实时分享（测试中）；所有付费计划可用，可导出到 Miro、Lucid、Airtable 或 .xlsx / CSV。HN 约 150 分、119 条评论。

    claude.com news.ycombinator.com
  3. 前 Meta 工程师：「AI 写代码让代码库变得脆弱」

    作者说在 Meta 的最后几个月，至少 90% 代码由 AI 生成才算达标，现在的新公司要求 100%；他列出 AI 让代码库变脆的几种方式，比如只写浅层测试、代码过度复杂、看不到上下文窗口之外的长期问题。评论区争论激烈。HN 约 350 分、386 条评论。

    evanxmerz.com news.ycombinator.com
  4. Val Town 宣布关停，2027 年 2 月开源

    创始人 Steve Krouse 称无法在云计算市场竞争：11 月 10 日起停止新注册和升级、暂停扣费，12 月 10 日进入只读，2027 年 1 月 10 日停止全部服务，2 月 1 日开源；年付用户部分退款，并提供迁移到 Cloudflare、Vercel、Netlify、Render 的指南。HN 约 284 分、75 条评论。

    blog.val.town news.ycombinator.com
  5. VulnCheck：Anthropic Glasswing 七个月，漏洞报告多、修复少

    VulnCheck 统计：Glasswing 可归到 Anthropic 的 CVE 有 442 个（约占今年 CVE 的 0.5%），仅 2 个被确认在野利用；37,966 条发现中只有 7,349 条公开、217 条标记已修复；curl 把 34 份公开报告中的 19 份判为不是漏洞，维护者被大量报告压得喘不过气。HN 约 113 分。

    vulncheck.com news.ycombinator.com
  6. Chrome、Edge、Firefox、MDN 联合推出 Modern Web Guidance，让编码 agent 别再写老式前端

    这是一套给编码 agent 用的 skills，内置 Web 平台最佳实践和浏览器兼容数据，引导 agent 用现代原生能力而不是遗留写法；一条 npx 命令安装，也能搜索指南、扫描代码库里的过时模式，已适配 Claude、Codex、Cursor 等插件格式。HN 约 229 分（Show HN）。

    github.com news.ycombinator.com
  7. X 爆料：苹果在做 Harbor，把多台 Mac 组成私有本地推理服务器

    爆料人 Aaron Perris 在 X 上披露，9to5Mac 跟进：Harbor 在 Apple 芯片上本地跑开源权重模型，数据不出设备，可通过 Thunderbolt 5 自动组网、合并多台 Mac 的统一内存来跑更大的模型；目前以 Claris 品牌私下预览。HN 约 89 分、43 条评论。

    9to5mac.com news.ycombinator.com
  8. 「智能家居应该断网也能用」：一位玩家十年的规则清单

    作者的核心设备都跑在自己的硬件上（ESP 板刷 Tasmota、MQTT、树莓派上的 Node-RED），规则包括断网时核心功能照常、不拆掉原来的开关、云设备必须有带日志的 API 才能装、配置集中一处。HN 今日最高分之一，约 654 分、232 条评论。

    docodethatmatters.com news.ycombinator.com

另外值得一看：Blender 5.3 原生支持 Gaussian Splat（约 414 分）、Synaptics 用专利威胁叫停 DisplayLink 开源驱动（约 266 分）、.name 域名老用户被「祖父条款」保留（约 641 分）、Ableton Live 13 发布（约 265 分）、.NET 11 运行时新特性（约 234 分）、AMD Zen 6 架构解析（约 175 分）、微软推出 macOS 版 Process Explorer（约 118 分）、推理工程开放指南（约 66 分）。

Morning tech digest · 2026-11-11

Morning brief (Asia/Shanghai): AI, open source, security, and actionable signals for one-person companies.

① Top stories

  1. DeepMind introduces AlphaProof Code, using AI agents to formally verify Signal’s actual protocol code

    DeepMind describes a multi-LLM agent framework: human experts and models turn Signal’s security goals into formal specifications, then agents powered by Gemini Carbon generate over six million lines of Lean proofs, flagging only about 1% for human review, in roughly four weeks; with two previously fixed real bugs reintroduced in an isolated copy, the system proved the buggy versions insecure. ~560 points and 174 comments on HN.

    deepmind.google news.ycombinator.com
  2. Anthropic launches Claude Whiteboards and Claude Sheets, and Dashboards becomes Claude Data

    Whiteboards (a shared board for brainstorming with Claude) and Sheets (spreadsheets with formulas and drop-downs that Claude builds and edits) launch in beta, while Claude Dashboards becomes generally available as Claude Data with certified queries and live sharing in beta; available on all paid plans, with export to Miro, Lucid, Airtable, or .xlsx / CSV. ~150 points and 119 comments on HN.

    claude.com news.ycombinator.com
  3. Ex-Meta engineer: AI usage generates a fragile codebase

    The author says generating at least 90% of his code with AI was the bar for a decent rating in his last months at Meta, and his new employer expects 100%; he lists ways AI makes codebases fragile, such as shallow tests, overly complex code, and blindness to long-term issues beyond the context window. Heated discussion. ~350 points and 386 comments on HN.

    evanxmerz.com news.ycombinator.com
  4. Val Town is winding down and will open-source in February 2027

    Founder Steve Krouse says Val Town could not compete in cloud computing: new signups and upgrades stop and billing pauses on Nov 10, read-only mode starts Dec 10, all services end Jan 10, 2027, and the code is open-sourced on Feb 1; annual prepaid users get partial refunds, with migration guides for Cloudflare, Vercel, Netlify, and Render. ~284 points and 75 comments on HN.

    blog.val.town news.ycombinator.com
  5. VulnCheck: seven months into Glasswing, many findings but few fixes

    VulnCheck counts 442 CVEs attributable to Anthropic (about 0.5% of this year’s CVEs), only two known exploited; of 37,966 reported findings, 7,349 are public and 217 marked fixed; curl rejected 19 of 34 published reports as non-vulnerabilities, leaving maintainers swamped with validation work. ~113 points on HN.

    vulncheck.com news.ycombinator.com
  6. Chrome, Edge, Firefox and MDN launch Modern Web Guidance to keep coding agents off legacy web patterns

    A set of skills for coding agents that embeds web platform best practices and browser compatibility data, steering agents toward modern native capabilities instead of legacy patterns; one npx command installs it, and it can search guides and scan a codebase for outdated patterns, with plugin formats for Claude, Codex, Cursor and others. ~229 points on HN (Show HN).

    github.com news.ycombinator.com
  7. Leak on X: Apple is building Harbor, turning Macs into a private local inference cluster

    Leaker Aaron Perris posted on X and 9to5Mac followed up: Harbor runs open-weight models locally on Apple silicon with data staying on device, automatically clusters Macs over Thunderbolt 5 to pool unified memory for larger models, and is in private preview under the Claris brand. ~89 points and 43 comments on HN.

    9to5mac.com news.ycombinator.com
  8. Smart home devices should work without the internet: one builder’s rules after years of tinkering

    The author runs everything that matters on hardware he owns (Tasmota on ESP boards, an MQTT broker, Node-RED on a Raspberry Pi), with rules like core functions must work offline, never remove the old way, cloud devices need an API with logs, and config lives in one place. One of today’s top HN posts, ~654 points and 232 comments.

    docodethatmatters.com news.ycombinator.com

Also worth a look: Blender 5.3 adds native Gaussian Splat support (~414 points), Synaptics patent claims stop work on open DisplayLink drivers (~266 points), .name Grandfathered (~641 points), Ableton Live 13 (~265 points), What’s new in the .NET 11 runtime (~234 points), AMD’s Zen 6 family: feeding the beast (~175 points), Process Explorer for macOS (~118 points), An open field guide to inference engineering (~66 points).
